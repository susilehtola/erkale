# Vendored libxckernel kernels

The exchange-correlation kernel contractions in this directory are
generated by [libxckernel](https://github.com/susilehtola/libxckernel):
the XC energy (order 0), Fock matrix (order 1) and response (order 2)
for the `lda`, `gga`, `mgga_tau`, `mgga_lapl`, `mgga` and `cmgga_tau`
(current-corrected meta-GGA) families, spin-restricted and unrestricted.
The kernels contain the XC terms only; Coulomb and exact exchange stay
in ERKALE.

Everything here except `regenerate.sh` and this file is machine-generated:
do not edit it. To update the kernels, change the libxckernel commit or
the selection in `regenerate.sh` and run it; it needs git and Python
>= 3.10 with sympy and numpy, and replaces the generated files. The
commit the files were generated from is recorded in `XCKERNEL_COMMIT`.
